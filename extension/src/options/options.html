AHK Hotstring Clipper

Hotstring folder

The folder that holds your .ahk files. The extension only ever reads and writes inside it.

Set up this folder to create Main.ahk, the one script to run, and General.ahk, a first category it includes. New categories you save to get included automatically.

After saving, restart

New hotstrings

Default options

Pre-ticked in the dialog for each new hotstring. You can still change them for any one hotstring.

With Instant on, a trigger that is the start of another one (;br and ;brb) fires first, so the longer one can never be typed. The dialog warns when that would happen.

Triggers

A prefix such as ; keeps hotstrings from firing in ordinary words. Leave it empty for none.

Source comment

Off keeps files at one line per hotstring and keeps page addresses out of files you share.

AutoHotkey

Leave empty to use the installed AutoHotkey v2. Test connection shows the one it finds.

Native host

The extension never writes files itself. A small program on this PC does that for it, so Chrome needs to be able to reach it.

Keyboard shortcut

Select text on a page and press Alt+Shift+H, or right-click it and choose Add as AHK hotstring.

Local only: nothing leaves this PC. The extension has no network access, and the host contains no networking code.
